# Genos Income Solution

Public GitHub Pages for the [Genos capability matrix](https://cedric-chan.github.io/Genos-Income-Solution/) and [AI Workflow Projects Gantt](https://cedric-chan.github.io/Genos-Income-Solution/workflow-projects.html).

`index.html` and `workflow-projects.html` are static publication artifacts. Detailed progress, owners, open tasks, and evidence are maintained in private Markdown project records; the Gantt is a manually reviewed public summary, not a live sync.

For each update, confirm the private source first, publish only approved non-sensitive facts, distinguish completed work from plans, update that page's `Updated` date, and verify the Pages deployment. See [AGENTS.md](AGENTS.md) for the publication checklist.
